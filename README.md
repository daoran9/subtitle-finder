# SubtitleFinder / 字幕检索台

Windows 和 Android 上的字幕检索与管理工具。按片名、季集号或视频文件查找字幕，预览后保存到本机，也可以为 115 网盘中的视频查找并保存字幕。

## 主要功能

- **115 云盘字幕**。扫码登录后，选一个视频找字幕，或选整个文件夹批量匹配。字幕直接保存到对应视频所在的云盘目录。
- **115 搜索与排序**。按名称查找当前目录及子目录里的文件和文件夹。支持按名称、添加时间或更新时间升降序排列。
- **更新提醒**。应用启动后会检查 GitHub 正式版，找到适用于当前平台的新版时提供发布页入口。也可以在「关于 → 检查更新」手动查询。
- **按视频名保存**。设置中的开关默认开启，适用于从本地视频搜索后的下载和 115 保存。关闭后使用字幕文件名。
- **手机预览**。预览面板占当前可见高度的 70%，字幕正文可单独滚动，操作按钮按宽度换行。
- **更精确的编号匹配**。统一识别横线、空格和连写形式，过滤编号明确不符的结果。

## 快速上手

- **按名称搜索**。输入中文名、英文名、原名或编号。剧集可加季集号，例如 `S01E02`。
- **从本地视频搜索**。在「视频文件」点「单个」选取视频，Windows 也可将文件拖入窗口。程序从文件名提取片名、年份和季集号，并在可用时追加指纹检索。
- **预览与下载**。打开结果查看字幕，必要时切换简体或繁体。先选保存目录，再点下载。也可勾选多个结果批量下载。

### 保存字幕到 115

1. 在「视频文件」点 **115**，选择登录端，点「生成二维码」后用 115 官方 App 扫码确认。
2. 浏览目录，或在搜索框输入文件夹名或文件名。从根目录可搜索整个云盘。排序可选名称、添加时间或更新时间。找到视频后点选它，再打开一条字幕结果预览。
3. 核对预览中的目标目录和文件名，点 **存到 115**。应用会在同一目录保存字幕，已有同名文件时会停止。

例如，为 `影片.1080p.mkv` 保存 SRT 字幕时，开启「设置 → 按视频名保存字幕」会生成 `影片.1080p.srt`。关闭开关则保留预览字幕的文件名，简繁转换使用转换后的文件名。该设置也适用于 115 批量匹配。本地视频下载开启该开关时沿用命名预设，本地批量匹配可单独选择命名格式。

同一登录端可能影响对应端的已有会话。以 SubtitleFinder 中显示的「已核对」端为准。退出应用后需重新扫码。支持的登录端和保存规则见 [115 使用说明](docs/115.md)。

### 批量匹配视频文件夹

在 115 进入目标目录，点「扫描当前文件夹」。默认处理缺少同目录字幕的视频。保存时会把字幕放到各视频所在目录。重启后重新扫码并扫描，可接着匹配仍缺字幕的视频。

本地文件夹支持识别同目录字幕和内封字幕，并可读取同名 NFO、`movie.nfo` 和 `tvshow.nfo` 补全搜索信息。本地和 115 都支持扫描子目录、排除花絮和样片。本地每批最多载入 500 部视频。115 默认扫描全部视频，也可以填写起止位置分段扫描。

设置中可分别填写「视频文件名排除」和「文件夹名排除」，每栏每行一条。视频栏可用 `*中字*` 或 `*-CHS.*` 跳过对应视频，文件夹栏可用 `Extras` 或 `花絮` 跳过整个子目录。保存后重新扫描，本地和 115 的两种批量匹配方式均使用过滤后的结果。旧版扫描排除规则会复制到两栏，可按需删改。

选好文件夹后，默认使用「手动挑选字幕」。点「查找候选」，按视频分组预览并勾选所需字幕，再一次保存。切换到「自动保存」后，可选每部保存 1 到 5 份，默认为 1 份。候选不足时只保存找到的合格字幕。如果搜索或读取失败导致少存，可以点击「重试」继续查找并补存。相同内容只保留一份，额外版本会追加 `.v2`、`.v3` 等后缀。

普通搜索、手动挑选和自动保存共用推荐顺序。已选视频且时长可用时，合格候选按最后一条有效字幕与视频结尾的时间差从小到大排列。时长相同或不可用时，继续按匹配身份、正文中的色花或 98 堂等来源标记和括号说明排序。已确认正文无效的结果会显示原因并禁用勾选。暂时读取失败时，可以点击「查看」重试。

「设置 → 字幕排除关键词」支持每行填写一个词或短语。搜索时匹配字幕标题和文件名，预览、校验和保存时也检查字幕正文，命中任意一项即排除。

「设置 → 最小字幕体积（KB）」默认 20 KB，填 0 关闭。以解压、编码统一和所选简繁转换后的文件大小为准。普通搜索、手动挑选和自动保存均跳过偏小的字幕，下载与存到 115 时也会检查。完整短片字幕低于门槛时，可调低后重新搜索。

「设置 → 仅保存匹配特征的字幕」默认关闭。保存特征预填了色花、98 堂等标记和 `[括号说明]`，每行一项，可自行删除、替换或添加。开启后，原字幕正文命中任意一项即可保存。手动搜索默认列出命中的字幕，点「显示其他」可展开其余结果预览。本地下载、存到 115 和批量匹配均会核对保存特征。

批量匹配支持 1 至 3 个并发任务，可以暂停、继续或重试。切换本地文件夹时会保留上一批未完成的任务和进度，重启后也可以点击「恢复上一批」。命名可选通用、Emby、Jellyfin、Plex 或视频同名。Windows 保存到视频所在目录，Android 保存到选取视频文件夹时授权的目录。

## 字幕来源与格式

- 「全部」会查询迅雷字幕、ASSRT、SubHD、SubtitleCat、YIFY Subtitles、Subf2m、MovieSubtitles、TVSubtitles、Addic7ed、AVSubtitles 和爱译网。本地视频可追加射手网和迅雷指纹查询，115 视频按名称查找。
- 支持筛选简体中文、繁体中文、英文和日文。结果会显示各来源的条数、耗时及失败原因。个别来源超时或返回 0 条时，其他来源仍可返回结果。
- ASSRT 可直接使用公开网页。有 Token 时优先调用官方 API，结果不可用时回退到公开网页。Token 仅在当前运行期间保留。
- 支持 SRT、ASS、SSA、VTT 和 MicroDVD SUB。ZIP、RAR 和 7z 会按季集、语言和版本挑选包内字幕。应用检查时间轴和内容，并统一以 UTF-8 保存。
- 中文字幕可用 OpenCC 生成简体或繁体副本，按字形转换并保留原文的地区用词。自定义词库每行填写一对 `简体=繁体`，转换时双向应用。
- 「设置 → 中文优先」选择默认中文检索语言。开启「自动简繁转换」后，中文预览和保存会使用优先的字形，预览时可切换回原文。

## 平台功能

- **Windows 右键菜单**。在设置中启用后，右键视频可直接查找字幕，右键文件夹可进入批量匹配。如果移动了便携包，打开一次新位置的程序即可更新右键入口。
- **Windows 自动校时**。选定本地视频、字幕和保存目录后可开始校时，结果另存为 `.synced.srt`。安装包与便携包均内置所需组件。
- **Android 目录授权**。通过系统选择器选取源视频和保存目录。手机预览、批量匹配与 115 保存均可在应用内完成。安装和构建说明见 [Android 文档](docs/android.md)。

## 数据与排查

- 本地视频用于提取文件名、媒体轨和指纹。搜索词和本次所需的指纹会发送给对应字幕来源，视频文件不会上传。115 登录 Cookie 仅保存在当前服务进程的内存中。
- 设置、缓存、日志和批量任务状态保存在本机。Windows 优先使用程序旁的 `SubtitleFinderData`。程序目录不可写时，数据会保存在系统应用数据目录。双击启动失败时可查看其中的 `logs/app.log`。
- 如果结果偏多或不准，试试完整片名、年份、季集号或者视频原名，再按语言和来源筛选。
