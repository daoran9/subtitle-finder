# 字幕检索台

一个本地运行的字幕搜索工具。它可以按片名、剧集名、视频文件名搜索字幕，支持预览字幕内容，并把字幕保存到你选择的位置。

## 下载使用

在 Releases 页面下载最新发布文件。

- Windows：优先下载 `SubtitleFinder Setup 1.1.3.exe` 安装包。也可以下载 `SubtitleFinder 1.1.3.exe` 便携包。
- Android：下载发布版 `.apk` 安装包，允许安装未知来源后打开。

首次运行时，Windows 可能会提示未知发布者。本程序目前没有 Windows 代码签名证书，请只从本仓库 Releases 页面下载发布文件。

Windows 桌面版会把日志、窗口状态、缓存等运行数据放在程序目录旁边的 `SubtitleFinderData`。如果安装目录不可写，会退回系统应用数据目录。想避免写入 C 盘，建议安装或解压到 E 盘等可写目录。

Android 版目前是实验版。搜索、预览、下载和视频文件夹扫描使用同一套内核。Android 5.1 及以上、常见 ARM 手机均可安装。

## 主要功能

- 多字幕源检索
- 中文、英文等语言切换
- 字幕内容预览
- 自定义保存目录
- 多个结果批量下载
- 视频文件夹扫描（Windows / Android）
- 最近搜索记录
- 每个字幕源的状态、结果数、耗时和错误提示

## 搜索建议

建议尽量精准搜索：

- 搜电影时，优先输入英文片名或中文片名。
- 搜剧集时，建议带上季集号，例如 `S01E01` 或 `1x01`。
- 搜视频文件时，可以直接使用文件名，程序会自动清理常见分辨率、编码组、年份等干扰字段。
- 如果结果太多，可以切换语言，或改用更完整的片名和季集号。

## 字幕源规则

默认选择“全部”时，程序不是机械地请求每一个来源，而是按关键词类型选择来源：

- 普通片名、剧集名、视频文件名：优先查询常规公开字幕源。
- 带季集号的剧集搜索：会生成片名加季集号的组合词，并过滤明显不匹配的集数。
- 能识别出特殊编号格式的关键词：会额外加入适配这种格式的专项来源。
- 响应很慢、限制较多或容易阻塞整体搜索的来源：默认不强制加入“全部”，需要时可在来源下拉框中单独选择。

这样做是为了避免某个慢源拖住整次搜索，同时让常规影视搜索更稳定。

如果你希望确认某个来源是否被使用，可以查看界面里的“来源状态”。每个来源都会显示搜索中、完成、无结果、超时或失败。

## 结果与下载

- 点击结果可以预览字幕内容。
- Windows 版先选择保存目录，再点击下载，文件会直接保存到该目录。
- Android 版先在系统弹窗里选择保存文件夹，再点击下载，文件会直接保存到该文件夹。
- Android 版扫描视频文件时，也需要先在系统弹窗里选择视频文件夹。
- 勾选多个结果后，可以批量下载。
- 搜索结果会按相关性、剧集信息和来源进行整理，但公开字幕站点返回的数据质量不一致，仍可能出现同一系列分散或命名不统一的情况。

## 常见情况

### Windows 双击没反应

常见原因是系统安全策略、杀毒软件拦截、运行目录无写入权限，或内置服务启动失败。桌面版会在程序目录旁边生成 `SubtitleFinderData/logs/app.log`。如果没有弹出窗口，先看这个日志文件。

如果使用安装包，建议安装到普通可写目录，例如 `E:\SubtitleFinder`。如果下载的是便携包，请先放到可写目录再运行。

### Android 安装后打不开

Android 版内置本机字幕服务，启动时需要几秒。首次安装如果系统拦截未知来源安装，需要在系统设置里允许本次安装。

### 某个来源一直搜索中

通常是该网站响应慢、临时不可访问、限制访问，或网络连接不稳定。程序会给单个来源设置超时，其他来源不会因此中断。

### 有些结果乱码

字幕文件常见编码并不统一。程序会尝试自动识别编码，但少数字幕仍可能因为原文件编码混乱而显示异常。

### 为什么搜索结果不全

字幕来源本身并不是完整数据库，不同网站收录范围、命名方式、语言分类都不同。建议同时尝试英文名、中文名、原始视频文件名和带季集号的关键词。

## 隐私说明

程序在本机运行，不需要账号、密码或付费密钥。搜索时会向所选字幕来源发送你输入的关键词，用于获取公开字幕结果。

Android 版使用系统文件夹选择器。程序只能访问你主动选择的保存目录或视频目录，不会读取手机全盘。
