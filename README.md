# 字幕检索台

一个本地运行的 Windows 字幕搜索工具。

它可以按片名、剧集名或视频文件名搜索字幕，支持预览字幕内容，并把字幕保存到用户选择的目录。

## 功能

- 多字幕源搜索
- 字幕语言切换
- 字幕内容预览
- 源级搜索状态显示
- 自定义下载目录
- 多结果批量下载
- 视频文件夹扫描
- 最近搜索记录

## 字幕源

默认“全部”会查询常规公开字幕源。

部分响应较慢或适用范围较窄的来源只会在关键词明显匹配时自动加入。

如果需要强制搜索某个来源，可以在下拉框里手动选择。

## 安装

```powershell
npm install
```

## 开发运行

启动网页版：

```powershell
npm start
```

启动桌面版：

```powershell
npm run app
```

## 打包

```powershell
npm run build:win
```

打包产物会生成到 `dist` 目录。

## 搜索策略

- 保留用户输入的原始关键词。
- 自动扩展部分常见中英文片名别名。
- 识别 `S01E01`、`1x01` 这类季集号。
- 单集搜索会过滤不匹配的剧集结果。
- 默认搜索会优先查询常规源，并按关键词自动加入匹配的专项源。
- 每个字幕源会显示完成状态、结果数和耗时。

## 说明

本工具只聚合公开可访问的字幕检索结果。

如果某个来源临时不可用，界面会显示对应来源的失败或超时状态，其他来源的结果仍会正常返回。
