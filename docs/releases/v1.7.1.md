# SubtitleFinder v1.7.1

## 本次更新

- **115 网盘保存**。扫码选择登录端后，可给单个视频找字幕，或选整个文件夹递归匹配。字幕保存到各视频所在目录，已有同名文件时保留原文件。
- **115 搜索与排序**。浏览目录时可按名称 A → Z、Z → A，或按添加时间新 → 旧、旧 → 新排序。在当前目录及其子目录里按名称搜索文件或文件夹，从根目录搜索覆盖整个云盘。
- **按视频名保存**。「设置 → 按视频名保存字幕」默认开启，适用于本地视频搜索后的下载及 115 保存。关闭后使用字幕文件名。
- **Android 预览**。预览面板占当前可见高度的 70%，字幕正文可以独立滚动。
- **更新提醒**。Windows 和 Android 启动时检查 GitHub 正式版。发现适合当前平台的新版时提供发布页入口，也可在「关于」手动检查。
- **编号检索**。统一识别横线、空格和连写形式，过滤编号明确不符的结果。

## 下载与升级

- `SubtitleFinder.Setup.1.7.1.exe` 为 Windows x64 安装包。
- `SubtitleFinder.1.7.1.exe` 为 Windows x64 便携包，放到可写目录后双击运行。
- `SubtitleFinder.Android.1.7.1.apk` 为 Android 发布签名包，可覆盖安装同签名的旧版。

Windows 程序首次运行时可能显示未知发布者。附件中的 `SHA256SUMS` 可用于核对下载文件。使用步骤见 [项目 README](https://github.com/daoran9/subtitle-finder/blob/v1.7.1/README.md)。
