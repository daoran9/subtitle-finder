# SubtitleFinder v1.1.6

这版补齐本地视频检索、Windows 自动校时、移动端文件操作和字幕编码兼容性。

## 下载文件

- `SubtitleFinder.Setup.1.1.6.exe`：Windows 安装包，适合长期使用。
- `SubtitleFinder.1.1.6.exe`：Windows 便携包，解压或放到可写目录后直接运行。
- `SubtitleFinder.Android.1.1.6.apk`：Android 发布签名包。

## 本次更新

- Windows 支持从系统选择单个视频和把视频拖入窗口；Android 支持从系统选择单个视频。两端都会保留视频指纹检索。
- Windows 新增字幕自动校时。它使用当前预览字幕和本地视频，另存 `.synced.srt`，支持进度、取消、低质量拒绝和同名避让。
- Windows 包内置 ffsubsync 0.5.1 与 LGPL shared FFmpeg，不需要另装 Python 或 FFmpeg。
- 新增扫描排除规则、自定义简繁词库、搜索缓存、批量任务恢复、NFO 元数据、内封字幕检测、压缩包字幕选择和多种媒体库命名方式。
- 下载字幕统一输出 UTF-8，兼容 GBK/GB18030、Big5、UTF-16、日文编码和常见双重乱码。
- 手动预览和下载遇到语言不符时改为提示，不再隐藏有效字幕；批量匹配仍会跳过明显错语言候选。
- 修复移动端触摸后的黄色焦点框，以及便携版右键菜单、旧右键命令迁移和运行数据位置问题。
- 保留原有字幕源、ASSRT 双通道、视频指纹来源和专项编号检索策略。

## 升级说明

- Android 包使用发布签名，只能由同一签名证书升级安装。
- Android 暂不包含自动校时，避免旧设备处理完整视频音轨时占用过高内存和 CPU。
- Windows 程序没有代码签名证书，首次运行可能显示未知发布者。请只从本仓库 Releases 页面下载。
- 字幕来源的可用性受站点、网络和限流影响；单个来源失败不会中断其他来源。
