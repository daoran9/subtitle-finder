# SubtitleFinder v1.1.5

这版主要补搜索结果整理、发布信息和双端构建细节。

## 更新内容

- 搜索结果改成先按片名归组，再按季集和来源排序。
- 中英文别名会尽量落到同一组里，系列结果不容易被打散。
- 来源状态会显示原始结果数和最终命中数。
- 新增搜索框一键清空按钮。
- 新增应用内“关于”弹窗，能直接查看源码仓库、许可证和非商用说明。
- 修正 About 弹窗关闭按钮样式。
- Android release 构建改走项目内 `.gradle-cache`，避免默认用户目录卡住 Gradle 下载。

## 下载文件

- `SubtitleFinder 1.1.5.exe`
- `SubtitleFinder Android 1.1.5.apk`
