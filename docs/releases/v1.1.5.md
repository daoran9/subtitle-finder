# SubtitleFinder v1.1.5

这版补齐本地视频批量匹配、任务恢复、搜索缓存、NFO 元数据、字幕校验和简繁转换。

## 更新内容

- 搜索结果改成先按片名归组，再按季集和来源排序。
- 中英文别名会尽量落到同一组里，系列结果不容易被打散。
- 来源状态会显示原始结果数和最终命中数。
- 原有 9 个字幕源全部保留。手动“全部”搜索仍会固定启动这 9 个来源。
- 专项编号检索继续保留用户原词，并同时尝试横线、空格和连写形式；结果合并不会误删只包含编号的字幕。
- 从本地视频搜索时，追加射手网指纹和迅雷指纹，不上传视频文件。
- ASSRT 同时接入官方 API 和公开网页。无 Token 可直接搜索；填写 Token 后优先使用 API，失败或无结果时自动切回网页。
- ASSRT Token 只保存在当前运行内存中，不写入本地配置或浏览器存储。
- 修复部分 Android 代理网络把 ASSRT 文件域名解析为 Fake-IP，导致能搜索但不能预览或下载的问题。
- 新增视频文件夹批量匹配，支持并发 1 至 3、暂停、继续和失败重试。
- 批量任务会保存扫描列表、进度、失败原因和重试次数。程序重启后，未完成批次恢复为暂停，正在搜索的项目恢复为待处理。
- 新增搜索缓存。完整结果有效 30 分钟；部分失败或无结果有效 5 分钟；带 ASSRT Token 的结果只留在当前运行内存。
- Windows 和 Android 扫描支持视频同名 NFO、`movie.nfo` 和 `tvshow.nfo`，可读取中英文名、年份、季集号、IMDb 和 TMDB 编号。
- NFO 只追加精准搜索词，不覆盖用户原词、固定影视别名或专项编号检索策略。
- 新增外置字幕和内封字幕检测，只处理缺少目标语言字幕的视频。
- 新增通用、Emby、Jellyfin、Plex、视频同名五种命名方式。
- ZIP、RAR、7z 下载包会按语言、季集号和发布版本自动选择字幕。
- 预览、下载和批量匹配会校验 SRT、ASS、SSA、VTT 和 MicroDVD SUB，拒绝网页、空文件、二进制内容、无时间轴和明显错语言字幕。
- 批量匹配会依次校验质量最高的 8 个候选，坏字幕会自动换下一条。
- 新增 OpenCC 简繁转换。下载生成 `.chs` 或 `.cht` 副本，不覆盖原字幕。
- 统一字幕质量分，综合语言、双语、季集、发布版本、格式、来源和下载量排序。
- 新增搜索框一键清空按钮。
- 新增应用内“关于”弹窗，能直接查看源码仓库、许可证和非商用说明。
- 修正 About 弹窗关闭按钮样式。
- 修复 Android 内置服务已经就绪，但页面仍停在“启动中”的时序问题。
- 修复搜索过程中再次点击“搜索”时，旧请求误报超时并覆盖新结果状态的问题。
- Windows 和 Android 使用同一套搜索、质量排序和压缩包选择规则。
