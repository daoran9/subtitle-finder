# SubtitleFinder v1.7.0

## 本次更新

- 新增 115 视频与字幕。可选择客户端扫码授权，浏览云盘目录并按视频查字幕，预览后可保存到视频所在目录。账户授权在程序退出后失效，同名字幕会保留。
- 设置新增“按视频名保存字幕”，同时适用于本地视频搜索后的字幕下载和 115 保存。关闭后使用字幕文件名。
- 手机预览面板提高到屏幕可见高度的 70%，正文可独立滚动，工具栏会随宽度换行。修复关闭设置后误触底层按钮的问题。
- 统一专项番号的识别、精确匹配和字幕筛选，改进恢复工具命名和站点发布前缀的处理。
- 修正 Windows 视频时长换算和控制台管道断开时的启动错误，并改进 Android 本地服务启动及批量任务恢复。

## 下载和升级

- `SubtitleFinder.Setup.1.7.0.exe` 为 Windows 安装包。
- `SubtitleFinder.1.7.0.exe` 为 Windows 便携包。
- `SubtitleFinder.Android.1.7.0.apk` 为 Android 发布签名包，可覆盖安装同签名的旧版。

Windows 包仍使用未签名的发布方式，系统可能显示未知发布者。115 同一登录端的会话可能互相影响，扫码后以应用显示的已核对登录端为准。用法见 [115 说明](../115.md)。
