# SubtitleFinder v1.7.3

## 本次更新

- **115 保存**。按文件 ID 确认视频仍在原目录，只读取对应扩展名的字幕来检查同名。上传后优先按回执的文件 ID 核对目录和内容。手动改搜索词后，可继续保存到原先选中的视频目录。
- **115 扫码和浏览**。等待扫码时收到空状态会继续轮询。文件和文件夹支持按更新时间排序，视频名旁会显示 115 提供的时长。
- **多视频批量保存**。同一个批次可为多部视频各选多份字幕。默认手动勾选，也可主动切换到「自动保存首选」。
- **字幕筛选和排序**。普通搜索和批量匹配可根据字幕正文推荐。设置中可编辑保存特征和排除关键词，保存特征同时适用于本地和 115。
- **编号匹配与简繁转换**。改进部分带前导零的视频编号识别。可设置简体或繁体优先，以及是否自动转换。OpenCC 标准配置保留原文的地区词汇。

## 下载与升级

- `SubtitleFinder.Setup.1.7.3.exe` 是 Windows x64 安装包。
- `SubtitleFinder.1.7.3.exe` 是 Windows x64 便携包，放在可写目录运行。
- `SubtitleFinder.Android.1.7.3.apk` 是 Android 签名安装包，可覆盖安装同签名的旧版。

附件中的 `SHA256SUMS` 可用于核对下载文件。使用步骤见 [项目 README](https://github.com/daoran9/subtitle-finder/blob/v1.7.3/README.md)。
