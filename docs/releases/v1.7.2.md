# SubtitleFinder v1.7.2

## 本次更新

- **115 更新时间排序**。浏览目录或搜索时，可按 115 记录的更新时间排序，支持从新到旧和从旧到新。置顶文件夹也参与排序。
- **迅雷字幕匹配**。从 115 视频提取标准编号后，用该编号检索。编号搜索会过滤无法核对编号的迅雷关键词结果，减少误匹配。
- **简繁转换**。升级 OpenCC 字典并使用标准简繁配置，按字形转换，保留字幕里的地区用词。仍可用自定义词库指定需要替换的词。

## 下载与升级

- `SubtitleFinder.Setup.1.7.2.exe` 为 Windows x64 安装包。
- `SubtitleFinder.1.7.2.exe` 为 Windows x64 便携包，放到可写目录后双击运行。
- `SubtitleFinder.Android.1.7.2.apk` 为 Android 发布签名包，可覆盖安装同签名的旧版。

附件中的 `SHA256SUMS` 可用来核对下载文件。使用步骤见 [项目 README](https://github.com/daoran9/subtitle-finder/blob/v1.7.2/README.md)。
