# SubtitleFinder v1.6.1

这是一版下载与移动端预览修复补丁。

## 下载文件

- `SubtitleFinder Setup 1.6.1.exe`：Windows 安装包，适合长期使用。
- `SubtitleFinder 1.6.1.exe`：Windows 便携包，放到可写目录后直接运行。
- `SubtitleFinder Android 1.6.1.apk`：Android 发布签名包。

## 本次更新

- 修复 Android 下载 SRT 时被系统追加 `.txt` 后缀的问题；现在按 SRT、ASS、SSA、VTT 和 SUB 的实际格式保存。
- Android 在保存字幕时显示“正在保存”和完成后的实际文件名，保存期间阻止重复点击。
- 复制字幕文本会显示复制中、成功或失败反馈；Android 增加 WebView 兼容回退。
- 手机预览固定在下半屏，结果区和搜索栏仍可滚动；预览时可直接回到搜索栏修改关键词或切换结果。
- 服务端下载响应按字幕扩展名返回 MIME 类型，避免把 SRT 误判为普通文本。

## 升级说明

- Android 包使用发布签名，可覆盖安装旧版；系统若提示安装包来源未知，请确认来自本仓库 Releases 页面。
- Windows 程序暂未使用代码签名证书，首次运行可能显示未知发布者。安装包和便携包都建议放在可写目录。
- 字幕来源的可用性受站点、网络和限流影响；单个来源失败不会中断其他来源。
