# SubtitleFinder v1.1.4

这版主要把 Windows 桌面版和 Android 端都补稳了。

## 更新内容

- Windows 桌面版新增启动失败弹窗、单实例锁、日志文件、窗口大小记忆。
- Windows 下载链路加固，只允许保存本地字幕服务返回的下载地址。
- Windows 文件名自动清理，优先使用响应头里的真实文件名。
- Windows 发布包分为安装包和便携包两种。
- 桌面运行数据默认放在程序目录旁边的 `SubtitleFinderData`。
- Android 端补齐保存目录选择、视频目录扫描和半屏字幕预览。
- 搜索结果、下载和预览流程都做了移动端适配。

## 下载文件

- `SubtitleFinder.Setup.1.1.4.exe`
- `SubtitleFinder.1.1.4.exe`
- `SubtitleFinder.Android.1.1.4.apk`
