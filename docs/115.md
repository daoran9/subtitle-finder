# 保存字幕到 115

视频文件栏点 **115**，选择登录端，生成二维码后使用 115 官方客户端扫描并确认。可选网页、115生活苹果、115苹果、安卓、iPad、安卓电视、Apple TV、115管理苹果、Windows、Linux、微信小程序、支付宝小程序和鸿蒙。各端可用性取决于 115 接口和账号状态。

同一登录端可能影响该端已有登录。Cookie 只保留在本次服务运行的内存里，不写配置、浏览器存储或日志；重启后需要重新扫码。退出只清除 SubtitleFinder 当前会话，不调用远端注销其他客户端。

生成二维码时按所选端使用对应系统的请求标识，不再给所有端固定发送 Windows 标识。手机确认页仍可能显示“iPhone 网页端”等名称；115 的二维码授权与扫码后的登录凭据换取是两个阶段。成功后，SubtitleFinder 会从服务器返回的 UID 核对端类型，并在账号旁显示“115生活 · 苹果（已核对）”等实际端；返回端与选择不一致时不保存该登录。苹果端和 115管理苹果端的换取请求分别使用 `UPhone/1.0.0` 与 `OfficePhone/1.0.0`；115管理苹果端共用 ios 接口。协议与端代码参考 [p115client 登录实现](https://github.com/ChenyangGao/p115client/blob/main/p115client/client.py)及[端代码表](https://github.com/ChenyangGao/p115client/blob/main/p115client/const.py)。

登录后进入视频所在目录，点击视频自动搜索。预览区会显示目标目录及文件名。**设置 → 按视频名保存字幕** 默认开启，例如 `影片.1080p.mkv` 对应 `影片.1080p.srt`；字幕格式和扩展名保留。关闭后使用预览字幕的文件名，选择简繁转换时使用转换后的文件名。该设置也适用于从本地视频搜索后下载字幕，本地视频开启时沿用命名预设。点 **存到 115** 后，字幕保存到视频所在目录。

云盘视频只按文件名搜索，不读取远程视频或计算本地指纹；射手网指纹和迅雷指纹需本地视频。当前 115 入口处理单个视频，不自动批量上传整个目录。

保存前重新读取目录，视频移动、更名或已存在同名字幕时停止，不覆盖。上传使用 115 初始化返回的 OSS 临时凭据，不把账号 Cookie 发送给 OSS。上传后读回文件名、大小及 SHA1，核对通过才显示成功。上传结果不明时不自动重试，当前会话阻止重复上传同一目标；先到 115 核对实际结果。
