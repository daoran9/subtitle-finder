# 保存字幕到 115

视频文件栏点 **115**，选择登录端，生成二维码后使用 115 官方客户端扫描并确认。可选网页、115生活苹果、115苹果、安卓、iPad、安卓电视、Apple TV、115管理苹果、Windows、Linux、微信小程序、支付宝小程序和鸿蒙。各端可用性取决于 115 接口和账号状态。

同一登录端可能影响该端已有登录。Cookie 只保留在本次服务运行的内存里，不写配置、浏览器存储或日志；重启后需要重新扫码。退出只清除 SubtitleFinder 当前会话，不调用远端注销其他客户端。

生成二维码时按所选端使用对应系统的请求标识，不再给所有端固定发送 Windows 标识。手机确认页仍可能显示“iPhone 网页端”等名称；115 的二维码授权与扫码后的登录凭据换取是两个阶段。成功后，SubtitleFinder 会从服务器返回的 UID 核对端类型，并在账号旁显示“115生活 · 苹果（已核对）”等实际端；返回端与选择不一致时不保存该登录。苹果端和 115管理苹果端的换取请求分别使用 `UPhone/1.0.0` 与 `OfficePhone/1.0.0`；115管理苹果端共用 ios 接口。协议与端代码参考 [p115client 登录实现](https://github.com/ChenyangGao/p115client/blob/main/p115client/client.py)及[端代码表](https://github.com/ChenyangGao/p115client/blob/main/p115client/const.py)。

在 115 浏览器中，可以按名称、添加时间或更新时间排序。名称可选 A → Z 和 Z → A，两种时间都可选旧 → 新和新 → 旧。更新时间使用 115 记录的修改时间。搜索框按名称查找当前目录及其子目录里的文件和文件夹。在根目录搜索可查找整个云盘。点击搜索结果中的文件夹可进入该目录，点击普通文件可打开其所在目录。

点击视频后自动检索字幕，预览区会显示目标目录及文件名。**设置 → 按视频名保存字幕** 默认开启，例如 `影片.1080p.mkv` 对应 `影片.1080p.srt`。字幕格式和扩展名保留。关闭后使用预览字幕的文件名，选择简繁转换时使用转换后的文件名。该设置也适用于从本地视频搜索后下载字幕，本地视频开启时沿用命名预设。点 **存到 115** 后，字幕保存到视频所在目录。

找不到合适的字幕时，可以在主界面修改搜索词后重搜。预览区会保留原来的 115 目标，选好字幕后仍可点 **存到 115**。目标可通过 **取消 115 目标** 解除。射手网指纹、迅雷指纹和内封字幕检查需要本地视频。

要批量匹配，进入目录后点 **扫描当前文件夹**。起点和终点都留空时，扫描当前目录及子目录里的全部符合规则的视频。只填起点会扫到最后，只填终点会从第一部扫起。位置按符合扫描规则的视频计数，包含已有字幕的视频。浏览页每页显示的文件和排序独立于批量扫描。载入后，可翻页点选视频，也可以开始批量匹配。

**设置 → 视频文件名排除** 可填写 `*-CHS.*` 等文件名规则。**文件夹名排除** 可填写 `花絮` 等文件夹名规则，命中后跳过整个子目录。每行一条，保存后重新扫描生效。

默认点 **查找候选**，再按视频勾选要保存的字幕。也可以选择 **自动保存**，设置每部保存 1 到 5 份，默认为 1 份。匹配时默认跳过已有外挂字幕的视频，手动挑选时可勾选 **包含已有字幕的视频** 一并处理。字幕存到各视频所在的目录，使用「按视频名保存字幕」开关指定的命名方式。查找时可暂停、继续和重试。

115 提供时长时，视频列表会在文件名旁显示时长。

保存前按文件 ID 确认视频仍在原目录，并检查同目录内同扩展名的字幕。视频移动、更名或已存在同名字幕时停止。上传使用 115 初始化返回的 OSS 临时凭据。上传后优先按回执里的文件 ID 核对目录、文件名、大小和 SHA-1，回执缺少可用 ID 时通过同目录字幕列表核对。上传结果不明时请到 115 查看实际结果，当前会话会阻止重复上传同一目标。
